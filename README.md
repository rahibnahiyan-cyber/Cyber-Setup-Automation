# Cyber Setup Automation

This is my personal repository for Linux setup, wallpapers, scripts, and practice files.

The goal is to keep everything I use for my personal workflow in one place so I can quickly restore it after reinstalling my system.

## Included files

- `install.sh` – personal setup script
- `install_termux.sh` – Termux setup script
- `Wallpaper/` – wallpapers and desktop customization files
- `Projects/` – personal project files
- `programming-test/` – Python and coding practice files
- `web-test/` – web security and learning practice files

## Notes

This repository is mainly for my personal use and organization.

It contains my setup files, practice work, and personal learning materials only.
